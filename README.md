  <h1>Genetik Algoritma ile Optimizasyon - C# Projesi</h1>
  <p>
    Bu proje, <strong>Genetik Algoritma</strong> (GA) yöntemini kullanarak sürekli bir fonksiyonun minimizasyonunu gerçekleştiren C# tabanlı bir uygulamadır.
    Kullanıcı arayüzü üzerinden parametreler girilerek en uygun çözüme ulaşılması sağlanır.
  </p>

  <h2>🎯 Proje Amacı</h2>
  <p>Amaç, reel-kodlu genetik algoritma kullanarak aşağıdaki formdaki bir uygunluk fonksiyonunun minimum değerini bulmaktır:</p>

  <pre><code>
f(x) = (x₁ - 3)² + (x₂ + 1)²
Aralık: x₁, x₂ ∈ [-2, 3]
  </code></pre>

  <h2>🛠️ Kullanılan Teknolojiler</h2>
  <ul>
    <li>C# (.NET Framework / .NET 6+)</li>
    <li>Windows Forms (WinForms)</li>
    <li>OOP (Nesne Yönelimli Programlama)</li>
    <li>Chart / Grafik</li>
  </ul>

  <h2>⚙️ Özellikler</h2>
  <ul>
    <li>Popülasyon büyüklüğü, nesil sayısı, çaprazlama/mutasyon oranı gibi ayarlanabilir parametreler</li>
    <li>Reel-kodlu kromozom yapısı</li>
    <li>İkili turnuva seçimi</li>
    <li>Aritmetik çaprazlama</li>
    <li>Rasgele mutasyon</li>
    <li>Uygunluk fonksiyonu ile değerlendirme</li>
    <li>Grafik ile en iyi bireyin evrimi</li>
  </ul>

  <h2>🧬 Genetik Algoritma Yapısı</h2>
  <ol>
    <li>Başlangıç popülasyonu oluşturma</li>
    <li>Fitness (uygunluk) hesaplama</li>
    <li>İkili turnuva ile seçim</li>
    <li>Aritmetik çaprazlama ile yeni birey üretimi</li>
    <li>Rasgele mutasyon</li>
    <li>Elitizm ile en iyi bireyleri koruma</li>
    <li>Belirli nesil kadar tekrar</li>
  </ol>
